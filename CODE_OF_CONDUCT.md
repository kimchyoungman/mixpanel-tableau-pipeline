# Code of Conduct

## Our Standards

Contributors must communicate respectfully, welcome constructive feedback, and
avoid harassment, personal attacks, discriminatory language, and publication of
another person's private information.

## Scope

This code applies in project repositories, issue trackers, reviews, discussions,
and other spaces where someone represents the project.

## Enforcement

Report unacceptable behavior privately to the repository owner through their
GitHub profile. Do not include private or sensitive details in a public issue.
Maintainers may edit or remove contributions and may temporarily or permanently
restrict participation when behavior threatens a safe and constructive project.

This policy is informed by the Contributor Covenant 2.1.
